# Hussain Lab website

Static website (plain HTML/CSS/JS, no build step) for the Hussain Lab, Department of Neurosurgery, University of Maryland School of Medicine.

## Publish with GitHub Pages
1. Create a free account at github.com and click **New repository** (name it e.g. `hussain-lab`, set it to Public).
2. On the new repo page choose **uploading an existing file**, drag in the *contents* of this folder (index.html must be at the top level, not inside another folder), and click **Commit changes**.
3. Go to **Settings > Pages**. Under *Build and deployment*, set Source to **Deploy from a branch**, Branch to **main** and folder to **/ (root)**, then Save.
4. After 1-2 minutes the site is live at `https://YOUR-USERNAME.github.io/hussain-lab/`.

## Editing later
Open any `.html` file in GitHub (pencil icon), change the text, and commit. The live site updates in a minute or two.
